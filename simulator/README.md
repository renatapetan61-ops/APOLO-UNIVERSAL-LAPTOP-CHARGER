# Simulador de hardware

O painel Android desta primeira versão usa dados fixos locais marcados como DEMO. Este diretório será a implementação independente do simulador de protocolo e cenários de falha.

Cenários planejados: bateria ausente, telemetria expirada, sensor inválido, temperatura elevada simulada, falha de comunicação e estado seguro. Nenhum cenário deve ativar hardware.
